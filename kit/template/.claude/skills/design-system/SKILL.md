# Дизайн-система {{APP}}

Статус: **v0.1** — стартовый набор (перенесён из BAR: универсальные правила). Токены проекта заполняются в разделах 4–6.
Правило из референса помечается источником `[Mobbin: App — экран]`; решение владельца — «(решение владельца)».

## 1. Принципы

1. Mobile-first, базовый вьюпорт 390×844. Десктоп — телефонная колонка `max-width: 430px` по центру.
2. Ощущение нативного приложения: large title, плотные списки, нижние шторки вместо модалок, отклик на нажатие
   (scale 0.97 + затемнение 8%).
3. Каталог `/design-system` — источник истины: нет в каталоге → нет в экране. Каждый компонент — со всеми состояниями.
4. Один главный акцент на экран.

## 2. Сетка и отступы

- Шаг сетки **4px**. Шкала: 4, 8, 12, 16, 20, 24, 32, 40, 48.
- Горизонтальный отступ экрана **16px**; между секциями 24–40; внутри карточки 12–16.

## 3. Тач-зоны и safe-area

- Минимальная тач-зона **44×44** (Apple HIG), даже если иконка 20–24 — расширять паддингом.
- Между соседними интерактивными элементами ≥ 8px.
- `viewport-fit=cover`; верх — `env(safe-area-inset-top)`; низ — `max(env(safe-area-inset-bottom), 16px)`.

## 4. Цвет

_Заполнить: таблица токенов `--bg`, `--surface`, `--surface-2`, `--fg`, `--fg-2`, `--fg-3`, `--accent`, `--accent-fg`,
`--border`, `--danger`, `--success`, `--tile`, `--tile-strong`; тема(ы)._

## 5. Типографика

_Заполнить: шкала (large title / display / title-2 / headline / body / subhead / footnote / caption), шрифты (локальные)._

## 7. Универсальные правила (проверены в BAR)

### Навигация и шторки
- Шторки и модальные слои живут **в хэше URL** (`#filters`, `#item-…`): системное «Назад» закрывает шторку, а не
  уходит со страницы; прямая ссылка с хэшем подкладывает запись без хэша.
- Длинный экран с крупным заголовком — закреплённые кнопки навбара (56) с первого пикселя; подложка с размытием
  и название проявляются, когда заголовок **подходит** к навбару.
- Разделы — отдельные страницы (главная с плитками → страница раздела → деталь в шторке), а не одна длинная
  страница с якорями (решение владельца).
- Плитка-раздел — **заголовок + число**, без перечисления содержимого и без «Например: …» (решение владельца).

### Движение
- Язык движения по платформе: `html[data-platform=ios|android]` (авто по UA). Длительности и кривые — **только токены**
  `--dur-*` / `--ease-*`. iOS: push справа 100% → 0, старая страница на 30% и темнеет, 400 мс `cubic-bezier(.32,.72,0,1)`;
  Android: shared axis X ±30 px + fade, 300 мс emphasized; «назад» — страница сжимается и уходит.
- Переходы страниц — View Transitions (`viewTransition` у `<Link>`/`navigate`); нет API — мгновенно, всё работает.
- Особых анимаций для отдельных карточек не придумываем — переход как у всех страниц (решение владельца).
- Закрытие — тоже анимация: шторка уезжает вниз (быстрый смах > 0,5 px/мс закрывает с короткого хода), тост уходит вниз.
- iPhone standalone: свой свайп назад от левого края, под страницей — настоящая предыдущая.
- Перетаскивание строк — как iOS: поднятая строка с тенью едет за пальцем, соседи расступаются, данные меняются на отпускании.
- Тени и свечения в массовых списках — градиентами, не `filter: blur` (60 к/с на сотне карточек).
- reduced-motion — только fade. Тактильный отклик `navigator.vibrate(10)` — только Android; на iPhone pressed обязателен.

### Формы
- Поля 56 (пилюля), многострочное — растёт по тексту; подпись над полем; плейсхолдер — простое «Введите текст», без примеров.
- Выбор из словаря — строка «иконка · подпись · значение ›» → шторка с радио. Параметры по умолчанию **пустые**
  («Выберите»), ничего не подставляем за пользователя.
- Количество — степпер одной ширины во всех строках, короткие единицы.
- Главное действие формы — в закреплённом навбаре; неполная форма — disabled + подсказка «Чтобы сохранить, нужно: …».
- Удаление — сразу, с тостом «Вернуть»; уход с несохранёнными правками — шторка-вопрос.

### Онбординг и установка (PWA)
- Онбординг — полный экран по хэшу поверх корня, только при первом запуске (прямая ссылка не перебивается; у кого
  уже есть данные — не показываем). «Назад» сверху слева со 2-го экрана — **единственный шаг назад**; свайп листает
  вперёд; кнопка «Далее»; системное «Назад» закрывает. Визуалы — настоящие компоненты. Последний экран — действие.
  Отдельный адрес для просмотра (не меняет данные).
- Страница установки: iPhone — шаги «Поделиться → На экран Домой»; Android — кнопка по `beforeinstallprompt`
  или путь через ⋮; браузер мессенджера — «откройте в Safari / Chrome». На продакшене — только она в браузере.
- Заставки запуска iPhone (`apple-touch-startup-image`) — без белой вспышки; `overscroll-behavior: none`.

## 9. Чек-лист визуальной проверки (для `/look` и `ui-inspector`)

- [ ] Ничего не выходит за 390px, нет горизонтального скролла.
- [ ] Все интерактивные элементы ≥ 44×44.
- [ ] Текст не обрезан неожиданно (обрезка только намеренная, с `…`).
- [ ] Контраст текста достаточный (≥ 4.5), вторичный текст читается.
- [ ] Отступы кратны 4, края экрана — 16px.
- [ ] Учтены safe-area сверху и снизу.
- [ ] Один главный акцент на экран.
- [ ] Состояния loading/empty не «прыгают» по геометрии относительно content.
- [ ] Нет ошибок в консоли; переходы и шторки проверены кадрами.
