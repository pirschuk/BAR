# Дизайн-система BAR

Статус: **черновик v0** — значения стартовые, уточняются через `/ref`.
Каждое правило из референса помечается источником: `[Mobbin: App — экран]`.

## 1. Принципы

1. Mobile-first, базовый вьюпорт 390×844. Десктоп — это телефонная колонка
   `max-width: 430px` по центру.
2. Ощущение нативного приложения: large title, плотные списки, нижние
   шторки вместо модалок, отклик на нажатие (scale 0.97 + затемнение).
3. Фото коктейля — главный визуальный элемент; интерфейс вокруг сдержанный.
4. Каталог `/design-system` — источник истины: нет в каталоге → нет в экране.

## 2. Сетка и отступы

- Шаг сетки **4px**. Шкала отступов: 4, 8, 12, 16, 20, 24, 32, 40, 48.
- Горизонтальный отступ экрана: **16px** (`px-4`).
- Между секциями: 24–32px; внутри карточки: 12px.
- Сетка карточек каталога: 2 колонки, gap 12px → ширина карточки
  (390 − 16·2 − 12) / 2 = **167px**.

## 3. Тач-зоны и safe-area

- Минимальная тач-зона **44×44px** (Apple HIG), даже если иконка 20–24px —
  расширять паддингом.
- Между соседними интерактивными элементами ≥ 8px.
- Верх: `padding-top: env(safe-area-inset-top)`; таб-бар/нижние кнопки:
  `padding-bottom: max(env(safe-area-inset-bottom), 16px)`.
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`.
- Таб-бар: высота 49px + safe-area; нижняя шторка: отступ снизу = safe-area + 16px.

## 4. Цвет (токены — CSS-переменные, используются через Tailwind)

Тёмная тема по умолчанию (бар, вечер), светлая — вторая.

| Токен | Назначение | Dark (старт) | Light (старт) |
|---|---|---|---|
| `--bg` | фон экрана | `#0E0E10` | `#F7F6F3` |
| `--surface` | карточки, шторки | `#1A1A1D` | `#FFFFFF` |
| `--surface-2` | поля, чипсы | `#26262A` | `#EFEDE8` |
| `--text` | основной текст | `#F5F5F7` | `#141414` |
| `--text-2` | вторичный | `#A1A1A8` | `#6B6B70` |
| `--text-3` | плейсхолдеры, подписи | `#6C6C73` | `#9A9A9F` |
| `--accent` | акцент, CTA | `#FF8A3D` (цедра) | `#E8661A` |
| `--accent-fg` | текст на акценте | `#1A0E05` | `#FFFFFF` |
| `--border` | разделители | `rgba(255,255,255,.08)` | `rgba(0,0,0,.08)` |
| `--danger` / `--success` | статусы | `#FF5A5F` / `#3DDC84` | `#D93A3F` / `#1E9E5A` |

Контраст: основной текст ≥ 4.5:1 к фону, крупный (≥ 18px bold) ≥ 3:1.

## 5. Типографика

Шрифт: системный стек `-apple-system, "SF Pro Text", Inter, Roboto, system-ui`
(локально, без CDN).

| Стиль | Размер / line-height / вес | Где |
|---|---|---|
| `large-title` | 34/41, 700 | заголовок экрана |
| `title-1` | 28/34, 700 | название коктейля на детальной |
| `title-2` | 22/28, 700 | заголовки секций |
| `headline` | 17/22, 600 | названия в списках, кнопки |
| `body` | 17/22, 400 | основной текст |
| `callout` | 16/21, 400 | метод приготовления |
| `subhead` | 15/20, 400 | ингредиенты |
| `footnote` | 13/18, 400 | подписи, мета |
| `caption` | 12/16, 500 | бейджи, теги |

Числа в рецептах (мл) — `font-variant-numeric: tabular-nums`.

## 6. Радиусы, тени, движение

- Радиусы: чипсы/кнопки — `full` (pill); карточки — **20px**; фото внутри
  карточки — 16px; шторка — 28px сверху; поле поиска — 12px.
- Тени: в тёмной теме не используются (разделение — `surface`); в светлой —
  `0 1px 2px rgba(0,0,0,.06), 0 4px 16px rgba(0,0,0,.06)`.
- Pressed: `scale(0.97)` + оверлей 8% за 100ms; отпускание 200ms
  `cubic-bezier(.2,.8,.2,1)`.
- Шторка: вход 320ms spring-подобный ease-out; фон-скрим `rgba(0,0,0,.4)`.
- Уважать `prefers-reduced-motion`.

## 7. Компоненты (обязательный набор каталога /design-system)

Каждый — со всеми состояниями: default, pressed, disabled, loading, empty
(где применимо).

- **Button**: primary / secondary / ghost / icon; высота 50px (L), 44px (M);
  icon-button 44×44.
- **Chip** (фильтр): высота 36px (+ тач-зона 44), паддинг 14px, активный —
  заливка `--text` и текст `--bg`; горизонтальный скролл без скроллбара,
  первый отступ 16px.
- **SearchBar**: высота 44px, иконка лупы 18px, кнопка очистки появляется
  при вводе, «Отмена» справа в фокусе (iOS-паттерн).
- **CocktailCard**: фото 1:1 (или 4:5), название `headline` до 2 строк с
  обрезкой, мета `footnote` (крепость/бокал); состояния default, pressed,
  loading (скелетон), empty (нет фото → плейсхолдер бокала).
- **Skeleton**: `surface-2` + мерцание 1.2s; повторяет геометрию реального
  компонента.
- **BottomSheet**: хэндл 36×5, радиус 28 сверху, детенты medium/large,
  закрытие свайпом вниз и по скриму.
- **ListRow / IngredientRow**: объём слева (tabular, `text-2`), название справа;
  высота ≥ 44px. `[Mobbin: Blue Apron — ингредиенты рецепта]`
- **EmptyState**: иконка 48px, заголовок `title-2`, текст `subhead`, CTA.
- **TabBar**: 3–4 таба, иконка 24px + подпись `caption`.

## 8. Паттерны из Mobbin

Формат записи: правило → значение → источник → файл в `refs/`.

- Ингредиенты: двухколоночная таблица «количество — название», количество
  выровнено по левому краю фиксированной колонкой, разделители между
  секциями, а не между строками. `[Mobbin: Blue Apron]` →
  `refs/mobbin/blue-apron-recipe-ingredients.jpg`
- Выбор порций — нижняя шторка с крупным колесом-пикером и одной
  primary-кнопкой во всю ширину (pill, высота ~50). `[Mobbin: BitePal]` →
  `refs/mobbin/bitepal-servings-sheet.jpg`

_Пополняется командой `/ref`._

## 9. Чек-лист визуальной проверки (для `/look` и `ui-inspector`)

- [ ] Ничего не выходит за 390px, нет горизонтального скролла.
- [ ] Все интерактивные элементы ≥ 44×44.
- [ ] Текст не обрезан неожиданно (обрезка только намеренная, с `…`).
- [ ] Контраст текста достаточный, вторичный текст читается.
- [ ] Отступы кратны 4, края экрана — 16px.
- [ ] Учтены safe-area сверху и снизу.
- [ ] Иерархия: один главный акцент на экран.
- [ ] Состояния loading/empty не «прыгают» по геометрии относительно content.
