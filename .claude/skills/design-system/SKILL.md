# Дизайн-система BAR

Статус: **v0.1** — стартовые токены + паттерны из 13 референсов Mobbin (Шаг 1).
Каждое правило из референса помечается источником: `[Mobbin: App — экран]`.

## 1. Принципы

1. Mobile-first, базовый вьюпорт 390×844. Десктоп — это телефонная колонка
   `max-width: 430px` по центру.
2. Ощущение нативного приложения: large title, плотные списки, нижние
   шторки вместо модалок, отклик на нажатие (scale 0.97 + затемнение).
3. Фото коктейля — главный визуальный элемент; интерфейс вокруг сдержанный.
4. Каталог `/design-system` — источник истины: нет в каталоге → нет в экране.

## 2. Сетка и отступы

- Шаг сетки **4px**. Шкала отступов: 4, 8, 12, 16, 20, 24, 32, 40, 48.
- Горизонтальный отступ экрана: **16px** (`px-4`).
- Между секциями: 24–32px; внутри карточки: 12px.
- Сетка карточек каталога: 2 колонки, gap 12px → ширина карточки
  (390 − 16·2 − 12) / 2 = **167px**, пропорция 3:4 → высота **223px**.
- Вертикальный ритм каталога: large title → 12 → поиск → 12 → чипсы →
  8 → счётчик → 12 → сетка. Между секциями детальной — 32px.

## 3. Тач-зоны и safe-area

- Минимальная тач-зона **44×44px** (Apple HIG), даже если иконка 20–24px —
  расширять паддингом.
- Между соседними интерактивными элементами ≥ 8px.
- Верх: `padding-top: env(safe-area-inset-top)`; таб-бар/нижние кнопки:
  `padding-bottom: max(env(safe-area-inset-bottom), 16px)`.
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`.
- Таб-бар: высота 49px + safe-area; нижняя шторка: отступ снизу = safe-area + 16px.

## 4. Цвет (токены — CSS-переменные, используются через Tailwind)

Тёмная тема по умолчанию (бар, вечер), светлая — вторая.

| Токен | Назначение | Dark (старт) | Light (старт) |
|---|---|---|---|
| `--bg` | фон экрана | `#0E0E10` | `#F7F6F3` |
| `--surface` | карточки, шторки | `#1A1A1D` | `#FFFFFF` |
| `--surface-2` | поля, чипсы | `#26262A` | `#EFEDE8` |
| `--text` | основной текст | `#F5F5F7` | `#141414` |
| `--text-2` | вторичный | `#A1A1A8` | `#6B6B70` |
| `--text-3` | плейсхолдеры, подписи | `#6C6C73` | `#7C7C81` |
| `--accent` | акцент, CTA | `#FF8A3D` (цедра) | `#C2500E` |
| `--accent-fg` | текст на акценте | `#1A0E05` | `#FFFFFF` |
| `--border` | разделители | `rgba(255,255,255,.08)` | `rgba(0,0,0,.08)` |
| `--danger` / `--success` | статусы | `#FF5A5F` / `#3DDC84` | `#D93A3F` / `#1E9E5A` |

Контраст: основной текст ≥ 4.5:1 к фону, крупный (≥ 18px bold) ≥ 3:1. Проверено (Итерация 1): `accent-fg` на `accent` — 8.1 (dark) / 4.7 (light); `text-2` — 7.5 / 4.9; `text-3` — 3.7 / 3.8 (только подписи и вычеркнутое).

## 5. Типографика

Шрифт: системный стек `-apple-system, "SF Pro Text", Inter, Roboto, system-ui`
(локально, без CDN).

| Стиль | Размер / line-height / вес | Где |
|---|---|---|
| `large-title` | 34/41, 700 | заголовок экрана |
| `title-1` | 28/34, 700 | название коктейля на детальной |
| `title-2` | 22/28, 700 | заголовки секций |
| `headline` | 17/22, 600 | названия в списках, кнопки |
| `body` | 17/22, 400 | основной текст |
| `callout` | 16/21, 400 | метод приготовления |
| `subhead` | 15/20, 400 | ингредиенты |
| `footnote` | 13/18, 400 | подписи, мета |
| `caption` | 12/16, 500 | бейджи, теги |

Числа в рецептах (мл) — `font-variant-numeric: tabular-nums`.

## 6. Радиусы, тени, движение

- Радиусы: чипсы и CTA шторок — `full` (pill); кнопки действий на
  детальной и кнопка фильтров — **12px** `[Mobbin: CREME]`; карточки —
  **20px** `[Mobbin: CREME, Crouton]`; миниатюры в списках — 8px; шторка —
  28px сверху; поле поиска — 12px.
- Скрим фото (текст поверх фото): `linear-gradient(to top, rgba(0,0,0,.72), transparent 60%)`
  для низа; сверху под стеклянные кнопки — `rgba(0,0,0,.35) → transparent 30%`.
- Стекло (кнопки и плашки поверх фото): `background: rgba(20,20,22,.45); backdrop-filter: blur(16px) saturate(1.4)`.
- Тени: в тёмной теме не используются (разделение — `surface`); в светлой —
  `0 1px 2px rgba(0,0,0,.06), 0 4px 16px rgba(0,0,0,.06)`.
- Pressed: `scale(0.97)` + оверлей 8% за 100ms; отпускание 200ms
  `cubic-bezier(.2,.8,.2,1)`.
- Шторка: вход 320ms spring-подобный ease-out; фон-скрим `rgba(0,0,0,.4)`.
- Уважать `prefers-reduced-motion`.

## 7. Компоненты (обязательный набор каталога /design-system)

Каждый — со всеми состояниями: default, pressed, disabled, loading, empty
(где применимо). Ссылки на референсы — `refs/mobbin/ANALYSIS.md`.

**Базовые**
- **Button**: `primary` (заливка `--accent`, текст `--accent-fg`),
  `secondary` (`--surface`), `ghost` (только текст), `icon`; размеры L 50px
  (CTA, pill), M 44px (действия, радиус 12), S 36px с тач-зоной 44.
  Вариант с ведущей иконкой Lucide 18px.
- **GlassIconButton**: круг 36px поверх фото (стекло), тач-зона 44 —
  назад / поделиться / избранное. `[CREME]`
- **Chip**: высота 36px (тач-зона 44), паддинг 14px, pill, обводка 1px
  `--border`; выбранный — заливка `--accent`, текст `--accent-fg`;
  опциональная иконка 16px и счётчик. Варианты: `filter` (в ряду) и
  `option` (в шторке, wrap).
- **ChipRow**: горизонтальный скролл без скроллбара, первым — кнопка
  «Фильтры» с иконкой и бейджем числа активных фильтров, затем
  вертикальный разделитель 1×20px, затем быстрые чипсы; ряд обрезается
  у правого края (видно, что он скроллится). `[NYT Cooking]`
- **Switch** + **SwitchRow** (заголовок 15 + подпись 13 `text-2` + switch). `[Mindtrip]`
- **SegmentedControl**: 2–4 сегмента, высота 36px, фон `--surface-2`,
  активный сегмент — `--surface` / в тёмной теме `--text` с текстом `--bg`.
  Используется для порций **1× / 2× / 4×**.
- **Skeleton**: `--surface-2` + мерцание 1.2s; повторяет геометрию реального
  компонента.

**Поиск**
- **SearchBar**: высота 44px, радиус 12, фон `--surface-2`, лупа 18px,
  плейсхолдер-вопрос («Что смешаем?»), ⓧ очистки при вводе; в фокусе
  справа «Отмена». Рядом — квадратная кнопка фильтров 44×44. `[CREME, Uber Eats]`
- **SuggestionRow**: высота ≥ 48px, ведущая иконка по типу (часы — недавнее,
  миниатюра — коктейль, лупа — фраза, бокал/лимон — ингредиент), текст с
  подсветкой совпадения; последняя строка «Искать „…“». `[Uber Eats]`
- **RecentRow**: миниатюра 36px радиус 8 + название 15 semibold + подпись
  13 `text-2`, разделитель с inset; высота 56px. `[CREME]`
- **IngredientSuggestChips**: «Ищете по ингредиенту?» — wrap-чипсы
  популярных ингредиентов на пустом поиске.
- **EmptyState**: иллюстрация/иконка в круге 96px, заголовок `title-2`,
  текст `subhead` `text-2` ≤ 2 строк, опциональная CTA «Сбросить фильтры»;
  **под ним всегда блок рекомендаций** (не тупик). `[Thrive Market]`

**Каталог и детальная**
- **CocktailCard**: вертикальная 3:4 (167×223 в сетке), радиус 20, фото на
  всю карточку, скрим снизу, название `headline` 2 строки белым поверх фото
  внизу слева (паддинг 12), мета — стеклянная плашка (крепость · бокал).
  Сверху справа — избранное (GlassIconButton S). Состояния: default,
  pressed (scale .97), loading (скелетон той же геометрии), no-image
  (градиент по цвету напитка + силуэт бокала). `[CREME, Crouton]`
- **CocktailHero**: фото ~55% высоты экрана, скрим в `--bg`, название
  `title-1` поверх, стеклянные кнопки сверху с учётом safe-area. `[CREME]`
- **StatGrid**: 4 колонки «подпись `footnote` `text-3` / значение `headline`»,
  с иконкой Lucide 20px; волосяные разделители сверху/снизу. Параметры:
  метод, бокал, лёд, крепость (крепость — сегментный индикатор 4 делений
  по `strength`). `[CREME, BitePal]`
- **IngredientRow (чек-лист)**: чекбокс 24px (тач-зона 44 на всю строку) ·
  объём справа tabular `headline` с единицей `footnote` · название `body`;
  отмеченный — зачёркнут и `text-3`. Объём пересчитывается от порций с
  короткой анимацией цифр. Высота 48px. `[Kitchen Stories, Blue Apron, CREME]`
- **SectionHeader**: `title-2` слева + действие справа (ссылка «Все» или
  контрол, например SegmentedControl порций).
- **BottomSheet**: хэндл 36×5, радиус 28 сверху, детенты medium/large,
  закрытие свайпом вниз, по скриму и ✕; шапка «Заголовок 20 bold + ✕»;
  **липкий футер** с safe-area. `[Fresha, Mindtrip]`
- **FilterSheet** (композиция): секции «Базовый алкоголь», «Вкус»,
  «Метод/Крепость» — wrap-чипсы `option` (первый — «Все»), секция
  «Мой бар» — SwitchRow «Только из того, что есть дома»; футер
  «Сбросить» (secondary pill) + «Показать N коктейлей» (primary pill,
  живой счётчик; N = 0 → кнопка disabled с текстом «Ничего не найдено»).
  `[Fresha, Insight Timer, Mindtrip]`
- **TabBar**: 3–4 таба, иконка 24px + подпись `caption`; фон — стекло,
  контент проходит под ним. `[Crouton]`

## 8. Паттерны из Mobbin

Формат: правило → значение → источник → файл в `refs/mobbin/`.
Полный разбор с ссылками — `refs/mobbin/ANALYSIS.md`.

**Общее**
- Тёмный фон без декора, единственный цвет на экране — фото напитков и
  акцент. → `[CREME]` → `1-catalog-creme-cocktail-collection.jpg`
- Акцент — тёплый персиковый/оранжевый с **тёмным** текстом на нём (как у
  CREME) — подтверждает `--accent` + `--accent-fg`. → `3-detail-creme-hero-stats.jpg`

**Каталог**
- Large title 34 → поиск 44 → ряд чипсов → счётчик результатов → сетка.
  → `[Crouton, NYT Cooking]` → `1-catalog-crouton-recipe-grid.jpg`, `1-catalog-nyt-cooking-filter-chips.jpg`
- Текст на карточке — поверх фото на скриме, не под фото: сетка
  выглядит как витрина, а не как таблица. → `[CREME, Crouton]`
- Мета на фото — стеклянной плашкой, не голым текстом. → `[Crouton]`
- Первый элемент ряда чипсов — «Фильтры» с бейджем, отделён разделителем.
  → `[NYT Cooking]`

**Поиск**
- Пустое поле → недавние + подсказки ингредиентов; ввод → типизированные
  подсказки с иконками; нет результата → объяснение + «Сбросить фильтры» +
  рекомендации. → `2-search-*.jpg`

**Детальная**
- Hero-фото с названием поверх, стеклянные кнопки сверху, затем ряд
  действий, затем 4-колоночный блок параметров между волосяными линиями.
  → `[CREME]` → `3-detail-creme-hero-stats.jpg`
- Порции — контрол в заголовке секции «Ингредиенты» (у нас
  SegmentedControl 1×/2×/4×, а не степпер: у коктейлей типично 1–4 порции).
  → `[CREME, Kitchen Stories]` → `3-detail-kitchen-stories-servings.jpg`
- Ингредиенты таблицей: объём — фиксированная колонка, выровнена,
  tabular; без разделителей между строками. → `[Kitchen Stories, Blue Apron]`
- При скролле — компактная шапка с названием. → `3-detail-creme-ingredients.jpg`

**Шторка фильтров**
- Секции с wrap-чипсами, разделитель + 24px между секциями; липкий футер
  из двух равных пилюль; primary показывает число результатов.
  → `[Fresha, Insight Timer]` → `4-sheet-fresha-filters.jpg`, `4-sheet-insight-timer-results-cta.jpg`
- Бинарные фильтры («Мой бар») — SwitchRow, а не чипс. → `[Mindtrip]` → `4-sheet-mindtrip-toggles.jpg`

**Что сознательно НЕ берём**
- Капс-заголовки CREME на всём подряд — только для hero коллекций.
- Сетка 3×N категорий с иллюстрациями (Blinkit) — для нашего каталога
  шумно; категории = чипсы.
- Светлые «бумажные» фоны (NYT, Blue Apron) — только в светлой теме.

_Пополняется командой `/ref`._

## 8½. Реализация в коде (Итерация 1)

- Токены — `src/styles/index.css`: CSS-переменные в `:root` / `:root[data-theme='light']`,
  проброшены в Tailwind через `@theme inline`. Дефолтная палитра Tailwind отключена
  (`--color-*: initial`) — «чужой» цвет в классе просто не соберётся.
- Классы цвета: `bg-bg`, `bg-surface`, `bg-surface-2`, текст — `text-fg` / `text-fg-2` /
  `text-fg-3` (= `--text`, `--text-2`, `--text-3`), `bg-accent` / `text-accent-fg`,
  `border-border`; поверх обложек — `text-on-media` / `text-on-media-2`.
- Типографика — классы `text-large-title` … `text-caption` (размер + line-height + вес).
- Размеры: `h-tap` 44, `min-h-row` 48, `h-btn-l` 50, `h-chip` 36, `size-glass-btn` 36,
  `max-w-app` 430; радиусы `rounded-card` 20, `rounded-control` 12, `rounded-thumb` 8,
  `rounded-check` 7; `aspect-card` 3:4; `h-hero` 55svh.
- Утилиты: `pressable` (оверлей 8%), `pressable-scale` (+ scale .97), `hit-44`
  (тач-зона 44 вокруг меньшего элемента), `glass`, `scrim-top` / `scrim-bottom`,
  `hero-fade`, `cover-gradient` (цвета из данных через `--cover-from/--cover-to`),
  `pt-safe` / `top-safe` / `pb-safe`, `no-scrollbar`.
- Состояние «pressed» на витрине — проп `pressed` → `data-pressed`.
- Тема: `src/lib/theme.ts` (`data-theme` на `<html>`, ключ `bar-theme` в localStorage);
  скриншот в нужной теме — `node scripts/screenshot.mjs <роут> <имя> --theme light`.
- Компоненты — `src/components/ui/`, витрина — `src/pages/DesignSystemPage.tsx`.

## 9. Чек-лист визуальной проверки (для `/look` и `ui-inspector`)

- [ ] Ничего не выходит за 390px, нет горизонтального скролла.
- [ ] Все интерактивные элементы ≥ 44×44.
- [ ] Текст не обрезан неожиданно (обрезка только намеренная, с `…`).
- [ ] Контраст текста достаточный, вторичный текст читается.
- [ ] Отступы кратны 4, края экрана — 16px.
- [ ] Учтены safe-area сверху и снизу.
- [ ] Иерархия: один главный акцент на экран.
- [ ] Состояния loading/empty не «прыгают» по геометрии относительно content.
- [ ] Текст поверх фото читается (есть скрим), стеклянные кнопки видны на светлом фото.
- [ ] Обе темы: тёмная (основная) и светлая.
