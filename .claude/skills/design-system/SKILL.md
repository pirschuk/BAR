# Дизайн-система BAR

Статус: **v0.3** — токены Итерации 1, язык рецепта v2 (Итерация 3: тинт, плитки, Unbounded), паттерны из 32 референсов Mobbin (Шаги 1, 3, 6). Тема одна — тёмная.
Каждое правило из референса помечается источником: `[Mobbin: App — экран]`.

## 1. Принципы

1. Mobile-first, базовый вьюпорт 390×844. Десктоп — это телефонная колонка
   `max-width: 430px` по центру.
2. Ощущение нативного приложения: large title, плотные списки, нижние
   шторки вместо модалок, отклик на нажатие (scale 0.97 + затемнение).
3. Фото коктейля — главный визуальный элемент; интерфейс вокруг сдержанный.
4. Каталог `/design-system` — источник истины: нет в каталоге → нет в экране.

## 2. Сетка и отступы

- Шаг сетки **4px**. Шкала отступов: 4, 8, 12, 16, 20, 24, 32, 40, 48.
- Горизонтальный отступ экрана: **16px** (`px-4`).
- Между секциями: 24–32px; внутри карточки: 12px.
- Сетка карточек каталога: 2 колонки, gap 12px → ширина карточки
  (390 − 16·2 − 12) / 2 = **173px**, пропорция 3:4 → высота **231px**.
- Вертикальный ритм каталога: large title → 12 → поиск → 12 → чипсы →
  8 → счётчик → 12 → сетка. Между секциями детальной — 32px.

## 3. Тач-зоны и safe-area

- Минимальная тач-зона **44×44px** (Apple HIG), даже если иконка 20–24px —
  расширять паддингом.
- Между соседними интерактивными элементами ≥ 8px.
- Верх: `padding-top: env(safe-area-inset-top)`; таб-бар/нижние кнопки:
  `padding-bottom: max(env(safe-area-inset-bottom), 16px)`.
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`.
- Таб-бар: высота 49px + safe-area; нижняя шторка: отступ снизу = safe-area + 16px.

## 4. Цвет (токены — CSS-переменные, используются через Tailwind)

Тема одна — тёмная (бар, вечер). Светлую убрали (решение владельца, Итерация 3).

| Токен | Назначение | Значение |
|---|---|---|
| `--bg` | фон экрана — чистый чёрный; **все градиенты уходят в него** | `#000000` |
| `--surface` | карточки, шторки | `#1A1A1D` |
| `--surface-2` | поля, чипсы | `#26262A` |
| `--text` | основной текст | `#F5F5F7` |
| `--text-2` | вторичный | `#A1A1A8` |
| `--text-3` | плейсхолдеры, подписи | `#6C6C73` |
| `--accent` | акцент, CTA | `#FF8A3D` (цедра) |
| `--accent-fg` | текст на акценте | `#1A0E05` |
| `--border` | разделители | `rgba(255,255,255,.08)` |
| `--danger` / `--success` | статусы | `#FF5A5F` / `#3DDC84` |
| `--tile` | плитки поверх тинта напитка | `rgba(255,255,255,.07)` |
| `--tile-strong` | круги иконок, пилюли, сегменты L на тинте | `rgba(255,255,255,.12)` |

Тинт напитка (`recipe-tint`) — не токен, а формула: `color-mix(cover.to 45%, --bg)` под обложкой,
дальше за ~760px (к концу ингредиентов) уходит в чёрный `--bg`. Обложки (`cover-gradient`): `from → to (50%) → --bg (90%)`. Текст на нём — `fg` / `fg-2`.

Контраст: основной текст ≥ 4.5:1 к фону, крупный (≥ 18px bold) ≥ 3:1. Проверено (Итерация 1): `accent-fg` на `accent` — 8.1; `text-2` — 7.5; `text-3` — 3.7 (только подписи). На тинте всех 51 рецептов `fg` и `fg-2` ≥ 4.5 — `node scripts/check-recipes.mjs`.

## 5. Типографика

Шрифт: системный стек `-apple-system, "SF Pro Text", Inter, Roboto, system-ui`
(локально, без CDN). Дисплейный — **Unbounded** (OFL, кириллица + латиница, variable woff2 в
`src/assets/fonts/`, ≈ 82 КБ, в precache PWA) — класс `font-display`, **только** `display` и
`section`. Unbounded широкий: 34px ≈ 10 символов на строку 358 → название ≤ 2 строк (`text-balance`).

| Стиль | Размер / line-height / вес | Где |
|---|---|---|
| `display` | 34/40, 700, Unbounded | название коктейля на обложке |
| `section` | 24/30, 600, Unbounded | заголовки секций рецепта |
| `card` | 14/19, 600, Unbounded | название на карточке каталога и ленты |
| `large-title` | 34/41, 700 | заголовок экрана |
| `title-1` | 28/34, 700 | название на карте «Мне повезёт» |
| `title-2` | 22/28, 700 | заголовки секций каталога и бара |
| `title-3` | 20/26, 600 | значения плиток параметров |
| `headline` | 17/22, 600 | названия в списках, кнопки |
| `body` | 17/22, 400 | основной текст |
| `callout` | 16/21, 400 | метод приготовления |
| `subhead` | 15/20, 400 | ингредиенты |
| `footnote` | 13/18, 400 | подписи, мета |
| `caption` | 12/16, 500 | бейджи, теги |

Числа в рецептах (мл) — `font-variant-numeric: tabular-nums`.

## 6. Радиусы, тени, движение

- Радиусы: чипсы и CTA шторок — `full` (pill); кнопки действий на
  детальной и кнопка фильтров — **12px** `[Mobbin: CREME]`; карточки —
  **20px** `[Mobbin: CREME, Crouton]`; миниатюры в списках — 8px; шторка —
  28px сверху; поле поиска — 12px.
- Скрим фото (текст поверх фото): `linear-gradient(to top, rgba(0,0,0,.72), transparent 60%)`
  для низа; сверху под стеклянные кнопки — `rgba(0,0,0,.35) → transparent 30%`.
- Стекло (кнопки и плашки поверх фото): `background: rgba(20,20,22,.45); backdrop-filter: blur(16px) saturate(1.4)`.
- Радиусы v2 (рецепт, Итерация 3): плитки параметров — **24** (`rounded-tile`), плитки
  ингредиентов и подсказки — **16** (`rounded-row`), сегменты L — пилюли; мета секций — текстом, без пилюли.
- Тени не используются (разделение — `surface` / `tile`).
- Pressed: `scale(0.97)` + оверлей 8% за 100ms; отпускание 200ms
  `cubic-bezier(.2,.8,.2,1)`.
- Шторка: вход 320ms spring-подобный ease-out; фон-скрим `rgba(0,0,0,.4)`.
- Уважать `prefers-reduced-motion`.

## 7. Компоненты (обязательный набор каталога /design-system)

> **История (язык v1, Итерации 1–2).** Числа в этом разделе и в 8½ — исходные; **действующие** — в 7½ и
> разделах ниже 8½: чипсы 44 (`callout`, без рамки, `bg-tile`), поиск и поля 56 (пилюля `bg-tile`), кнопки навбара 56,
> карточка каталога r 24 + название `card` Unbounded 14, SegmentedControl — только пилюля 44, EmptyState без иконки,
> StickyHeader — стекло без линии. При расхождении верь 7½.

Каждый — со всеми состояниями: default, pressed, disabled, loading, empty
(где применимо). Ссылки на референсы — `refs/mobbin/ANALYSIS.md`.

**Базовые**
- **Button**: `primary` (заливка `--accent`, текст `--accent-fg`),
  `secondary` (`--surface`), `ghost` (только текст), `icon`; размеры L 50px
  (CTA, pill), M 44px (действия, радиус 12), S 36px с тач-зоной 44.
  Вариант с ведущей иконкой Lucide 18px.
- **GlassIconButton**: круг 36px поверх фото (стекло), тач-зона 44 —
  назад / поделиться / избранное. `[CREME]`
- **Chip**: высота 36px (тач-зона 44), паддинг 14px, pill, обводка 1px
  `--border`; выбранный — заливка `--accent`, текст `--accent-fg`;
  опциональная иконка 16px и счётчик. Варианты:
  - `filter` — в ряду каталога, переключатель (✓ слева, когда включён);
  - `facet` — фасет с шевроном ⌄ справа («Вкус ⌄»); активный — заливка и
    значение вместо названия («Кислый +1 ⌄»); тап открывает шторку только
    этого фасета `[Viator, Tripadvisor, GitHub]`;
  - `option` — wrap внутри шторки и «Моего бара»: невыбранный — обводка и «+»
    слева, выбранный — заливка и «✓» (действие видно до тапа) `[Cherrypick]`;
  - `removable` — выбранный элемент над результатами поиска: заливка `surface-2` + «×»
    `[Kitchen Stories, MyFitnessPal]`.
- **ChipRow**: горизонтальный скролл без скроллбара, первым — кнопка
  «Фильтры» с иконкой и бейджем числа активных фильтров, затем
  вертикальный разделитель 1×20px, затем чипсы-переключатели и фасеты;
  ряд обрезается у правого края (видно, что он скроллится). Когда фильтры
  активны, в конце ряда — текстовая кнопка «Сбросить».
  `[NYT Cooking, Google Drive, Tripadvisor]`
- **Switch** + **SwitchRow** (заголовок 15 + подпись 13 `text-2` + switch). `[Mindtrip]`
- **SegmentedControl**: 2–4 сегмента, высота 36px, фон `--surface-2`,
  активный сегмент — `--surface` / в тёмной теме `--text` с текстом `--bg`.
  Используется для порций **1× / 2× / 4×**.
- **Skeleton**: `--surface-2` + мерцание 1.2s; повторяет геометрию реального
  компонента.

**Поиск**
- **SearchBar**: высота 44px, радиус 12, фон `--surface-2`, лупа 18px,
  плейсхолдер-вопрос («Что смешаем?»), ⓧ очистки при вводе; в фокусе
  справа «Отмена». Рядом — квадратная кнопка фильтров 44×44. `[CREME, Uber Eats]`
- **SuggestionRow**: высота ≥ 48px, ведущая иконка по типу (часы — недавнее,
  миниатюра — коктейль, лупа — фраза, бокал/лимон — ингредиент), текст с
  подсветкой совпадения; последняя строка «Искать „…“». `[Uber Eats]`
- **RecentRow**: миниатюра 36px радиус 8 + название 15 semibold + подпись
  13 `text-2`, разделитель с inset; высота 56px. `[CREME]`
- **IngredientSuggestChips**: «Ищете по ингредиенту?» — wrap-чипсы
  популярных ингредиентов на пустом поиске.
- **EmptyState**: иллюстрация/иконка в круге 96px, заголовок `title-2`,
  текст `subhead` `text-2` — **одна** строка-подсказка, что сделать
  («Уберите часть фильтров»); **одно** действие: secondary-кнопка M
  «Сбросить фильтры»; блок по центру свободной высоты.
  **Под ним всегда блок рекомендаций** (не тупик).
  `[Thrive Market, Careem, GitHub, Google Drive]`

**Каталог и детальная**
- **CocktailCard**: вертикальная 3:4 (173×231 в сетке), радиус 20, фото на
  всю карточку, скрим снизу, название `headline` 2 строки белым поверх фото
  внизу слева (паддинг 12), под ним — бокал `footnote` `on-media-2`;
  стеклянная плашка сверху — **крепость словом** («Крепкий», «Безалкогольный»),
  те же слова, что в фильтре «Крепость» (решение владельца, Шаг 5; проценты — только в рецепте).
  Сверху справа — избранное (GlassIconButton S). Состояния: default,
  pressed (scale .97), loading (скелетон той же геометрии), no-image
  (градиент по цвету напитка + силуэт бокала). `[CREME, Crouton]`
- **CocktailHero**: обложка ~55% высоты экрана, скрим, название `display` (Unbounded) поверх,
  низ растворяется в тинт напитка, стеклянная «Назад» сверху с учётом safe-area. `[CREME, Alma]`
- **ParamTiles** (v2, вместо StatGrid): 2×2, gap 12, плитка `tile` r 24; **сверху подпись** `footnote`
  `fg-2` с иконкой 16, **под ней значение** `title-3` одной строкой (если хоть одно > 11 символов —
  вся сетка `headline`). Крепость — **словом и цветом** шкалы `--strength-*` (зелёный → жёлтый →
  оранжевый → красный), без делений. `[Mindvalley, Vocabulary]`
- **AvailabilityLine** (Шаг 8) — информер наличия над списком: точка + текст, без подложки и кнопки.
- **IngredientList + IngredientTile**: общая сетка `название | число | единица` (subgrid) — числа по

  min-h 52, gap 8; не кнопка. Без числа («долить», «по вкусу») — слово стилем значения `headline`.
- **GarnishNote** — украшение тихой строкой под списком, как в Итерации 1: «Украшение: апельсиновая
  цедра» (`subhead`, подпись `fg-2`, значение `fg`, строчными). Плитка и строка-«украсить» отвергнуты владельцем.
- **NavBar** (правки владельца): кнопки «Назад» и действие (♡ / «+») — **56** (`size-nav-btn`, иконка 28)

  контейнер становится корнем backdrop-filter и размывать нечего. `tone="cover"` — стекло на обложке,

- **IconButton size="l"** — 44, иконка 24: «Назад» на обложке рецепта.
- **SectionHeader**: m — `title-2` слева + действие справа (ссылка «Все» или контрол);

- **FilterSheet** (композиция): секции «Ингредиент» (если выбран из поиска,

## 7½. Язык v2 — итог (эталон: страница коктейля, Итерация 3)

Утверждён владельцем 2026-10-23. **Это действующие правила**; исторические разделы ниже
(Шаги 6 и 8) объясняют, как к ним пришли. Каталог, «Мой бар» и шторки пока на языке v1 —
переносим следующими итерациями по чек-листу в конце раздела.

**Основа**
- Тема одна — тёмная; фон — чистый чёрный `#000`; **все градиенты уходят в чёрный**: обложки
  `from → to (50%) → чёрный (90%)`, тинт страницы — цвет напитка под обложкой → чёрный к концу
  первого крупного блока (~760px).
- Цвет — у контента, не у хрома: цвет напитка (обложка, тинт), цвет крепости
  (`--strength-*`: зелёный → жёлтый → оранжевый → красный), один акцент `#FF8A3D`.
- Заголовки с характером — Unbounded (`display` 34/40 на обложке, `section` 24/30 у секций);
  остальное — системный шрифт.
- Крупнее и круглее: плитки r 24 (параметры) и r 16 (строки), пилюли у сегментов L, тач-зоны ≥ 44.
- Плитки — полупрозрачные `--tile` поверх тинта/чёрного, без теней и рамок.

**Иерархия и раскладка**
- Подпись над значением: в плитке сверху подпись `footnote` `fg-2` с иконкой 16, под ней значение.
- Заголовок секции L: Unbounded слева, короткая мета **текстом** `subhead` `fg-2` справа по базовой
  линии («~3 мин»); контрол (1×/2×/4×) — строкой ниже, вспомогательный итог («≈ 90 мл», при 2× — «≈ 180 мл») — справа от него.
- Список однотипных строк — плитки r 16, gap 8, общая сетка колонок: числа по правому краю,
  колонка единиц по самой длинной; слово вместо числа («долить») — стилем значения.
- Статус — **информер**, не блок: точка 8 + текст, без подложки, рамки и кнопки («● Нет дома: Кампари»).
  Действие (отметить наличие) — на своём экране, не в статусе.
- Второстепенное — тихой строкой под списком («Украшение: апельсиновая цедра»), без плитки.

### Движение (Итерация 5)

- Язык движения — по платформе: `html[data-platform=ios|android]` (`lib/motion.ts`, авто по UA, переключатель на витрине). Длительности и кривые — **только токены** `--dur-*` / `--ease-*` в `index.css`, без чисел в компонентах.
- iOS (UIKit): вглубь — новая страница справа 100% → 0, старая уезжает на 30% и темнеет; назад — обратно; 400 мс `cubic-bezier(.32,.72,0,1)`. Шторка — 420 мс та же кривая, уход 250 мс.
- Android (Material 3): вглубь — shared axis X ±30 px + fade, 300 мс emphasized; назад — страница сжимается до 90% и уходит вправо; вкладки — fade-through.
- Переходы страниц — View Transitions (`viewTransition` у `<Link>`/`navigate`); вид перехода — `html[data-nav=forward|back|tab|grid|none]`. Нет API — мгновенно, всё работает.
- Карточка → рецепт — **обычный переход вглубь**, как у всех страниц (решение владельца, 18c): без общих элементов и особых анимаций для карточки.
- Закрытие — тоже анимация: шторка уезжает вниз (быстрый смах > 0,5 px/мс закрывает с короткого хода), скрим гаснет, тост уходит вниз. Шторка на время выхода держит прежнее содержимое.
- Сетка каталога при смене фильтров перестраивается (`data-nav=grid`, карточки — `--vt`); при наборе в поиске — без перехода.
- iPhone standalone: свой свайп назад от левого края (24 px), под страницей — настоящая предыдущая страница на своём скролле, сдвинута на 30% и притемнена. Корни вкладок — без жеста.
- reduced-motion — только fade 150 мс.
- Тактильный отклик `haptic()` — Android (вибрация 10 мс) на ♡, переключателях, строках +/✓, «Сохранить»; на iPhone из веба его нет — pressed обязателен везде.

### Картинки напитков (Итерация 7)

- Картинка коктейля — `DrinkArtReal`, собирается из рецепта, а не рисуется вручную: так работает и для авторских. Без украшений (решение владельца).
- Бокал — по профилю (полуширина на высоте) в ракурсе 3/4: эллипсы горлышка и дна (сплющенность 0.17), толстое донышко у стаканов, блики по краям (френель), ножка и подставка; медная кружка — металл, напиток виден сверху.
- Цвет напитка — `drinkColor` (`lib/drinkLook.ts`): смесь `look.color` ингредиентов по объёму × `look.tint`; прозрачная смесь остаётся прозрачной (плотность 0.28 + окрашенность), непрозрачное (сливки, пюре) — плотнее.
- Лёд по полю `ice`: объёмные кубики, крупный куб, шар, колотый; блендер — плотная масса с инеем. Пена — у белка, пузырьки — у газировки и игристого, сливки сверху — у build со сливками, запотевание — у холодных стаканов.
- Тень и отсвет на «столе» — радиальные градиенты, **не** `feGaussianBlur`: сотня карточек в каталоге держит 60 к/с.
- Силуэт `GlassIllustration` остаётся там, где речь о самом бокале (азбука) и в редакторе, пока бокал не выбран.
- Проверка: витрина → контактный лист всей базы; скрипт ищет NaN/Infinity, вылезание за рамку, пустые.
