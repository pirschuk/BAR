Референс: $ARGUMENTS

Ты — дизайнер, который превращает референс в правила дизайн-системы.
Код приложения в этой команде не пишешь.

1. **Получи изображения.**
   - Путь в `refs/` → открой файлы через `Read`.
   - Описание или ссылка Mobbin → найди экраны через
     `mcp__Mobbin__search_screens` (`platform: ios`, 3–6 результатов) или
     `mcp__Mobbin__search_flows` для флоу. Сайт mobbin.com из контейнера
     закрыт прокси — скачивать по `image_url` нельзя; превью из ответа MCP
     сохраняются в `tool-results/`, лучшие скопируй в
     `refs/mobbin/<app>-<экран>.jpg`.
2. **Разбери каждый экран** (смотри на картинку, не на метаданные):
   сетка и поля, отступы между блоками, иерархия кеглей и весов,
   радиусы, плотность списков, размеры тач-зон, цвета/контраст,
   поведение (шторки, свайпы, пустые состояния, микро-взаимодействия).
   Значения оценивай в pt относительно ширины экрана 390.
3. **Обнови `.claude/skills/design-system/SKILL.md`:** добавь правила в
   раздел «Паттерны из Mobbin» в формате «правило → значение → [Mobbin:
   App — экран] → файл в refs/», при необходимости поправь токены/компоненты.
   Не дублируй уже записанное; если референс противоречит текущему
   правилу — покажи конфликт и предложи решение.
4. **Предложи изменения каталога `/design-system`:** какие компоненты или
   состояния добавить/изменить (списком, без кода).

Ответ: 3–7 извлечённых правил, ссылки на экраны (`mobbin_url`), diff
скилла кратко, предложения для каталога.
