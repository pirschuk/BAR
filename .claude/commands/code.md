argument-hint: [уточнение]
---

Дополнительно: $ARGUMENTS

1. Прочитай `plan.md`. Если статус не «утверждён» и пользователь в этом
   сообщении явно не утвердил план — остановись и спроси.
   Прочитай `.claude/skills/design-system/SKILL.md`; для данных —
   `.claude/skills/cocktail-data/SKILL.md` (наполнение рецептов делегируй
   субагенту `bartender`).
2. **Каталог первым.** Для каждого компонента из «нужно добавить»:
   реализуй его на токенах и добавь в страницу `/design-system` со всеми
   состояниями (default, pressed, disabled, loading, empty — где
   применимо) и интерактивными переключателями.
3. Сними `/design-system` и проверь: `node scripts/screenshot.mjs /design-system ds --full`,
   открой png через `Read`, исправь огрехи.
4. **Экран.** Собери экран только из компонентов каталога. Новых
   «одноразовых» стилей не заводить — если не хватает, вернись к шагу 2.
5. **Визуальная проверка экрана** во всех состояниях из плана
   (скриншоты → `Read` → правки → повтор, пока чисто). Для независимого
   взгляда запусти субагента `ui-inspector` и закрой его P0/P1.
6. `npm run build` должен проходить.
7. Отметь в `plan.md` выполненные критерии готовности, статус «сделано».
8. Ответ: что добавлено в каталог, что в экран, пути к финальным
   скриншотам, что осталось.
