# Референсы

- `mobbin/` — экраны из Mobbin (превью из Mobbin MCP или скриншоты, которые
  скидывает пользователь). Имя файла: `<зона>-<тип>-<app>-<экран>.jpg` (зоны: 1 каталог, 2 поиск, 3 детальная, 4 шторка). Разбор — `ANALYSIS.md`.
- Правила, извлечённые из референсов, живут в
  `.claude/skills/design-system/SKILL.md` (раздел «Паттерны из Mobbin»)
  со ссылкой на файл отсюда.
- Добавить новый референс: положить файл сюда и выполнить `/ref refs/mobbin/<файл>`.
