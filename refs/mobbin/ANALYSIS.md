# Разбор референсов Mobbin — Шаг 1

Дата: 2026-10-22. Платформа: iOS. Превью — низкое разрешение из Mobbin MCP
(299px по ширине ≈ 390pt; значения ниже пересчитаны ×1.3, точность ±2pt).
Drinkin в базе Mobbin не найден; ближайший по духу аналог — **CREME**
(тёмный фуд/коктейльный каталог с фото-карточками).

★ — ключевой референс (8 шт.), остальные — вспомогательные.

![Доска референсов](../../docs/previews/step1-refs-board.png)

## Зона 1. Главный экран каталога

### ★ CREME — коллекция «Fresh Cocktails» · `1-catalog-creme-cocktail-collection.jpg`
[mobbin](https://mobbin.com/screens/de13a66b-7948-40e6-b724-6a9751bb294d)
- Чисто-чёрный фон, фото — единственный цвет на экране. Это наша «барная» эстетика.
- Hero-обложка во всю ширину с заголовком капсом ~34pt bold прямо на фото,
  снизу фото уходит в фон градиентом.
- Карточки 2 колонки, **вертикальные ~3:4**, радиус ~20pt, название 2 строки
  semibold белым **поверх фото** внизу слева на тёмном градиенте.
- Кнопки действий: primary — белая заливка, secondary — тёмная `surface`;
  высота ~42pt, радиус ~12pt (скруглённый прямоугольник, не pill).

### ★ Crouton — «All Recipes» · `1-catalog-crouton-recipe-grid.jpg`
[mobbin](https://mobbin.com/screens/45d8071c-4dfb-4274-96c9-83f473472322)
- Large title 34pt + поиск под ним (высота ~40–44pt, радиус 12, фон `surface-2`).
- Сетка 2×N: поля 16pt, gap ~12pt, карточка ≈1:1, радиус ~20pt.
- Название — **сверху слева поверх фото** (белый bold 17pt, до 3 строк),
  мета — **стеклянная плашка** (blur + полупрозрачность) внизу слева: иконка + число.
- Плавающий «стеклянный» таб-бар, контент проходит под ним.

### ★ NYT Cooking — сохранённые с фильтрами · `1-catalog-nyt-cooking-filter-chips.jpg`
[mobbin](https://mobbin.com/screens/304d5760-05ce-487a-8604-4c4f3e45fc1b)
- Ряд чипсов: **первым — кнопка «+ Фильтр»**, за ней вертикальный
  разделитель, далее быстрые чипсы-пилюли (обводка, ~34–36pt), ряд уходит
  за правый край (подсказка скролла).
- Под чипсами — счётчик результата «7 recipes» (footnote, `text-2`).
- Название под фото, bold, 2 строки с `…`.

## Зона 2. Поиск, подсказки, пустой результат

### ★ CREME — поиск, недавние · `2-search-creme-recent.jpg`
[mobbin](https://mobbin.com/screens/81c1a9c1-6a37-44fe-a2bc-557a58ee9b1b)

  с отступом от начала текста (inset), высота строки ~56pt.

- Кнопка очистки ⓧ внутри поля справа, стрелка назад вместо «Отмена».

### ★ Thrive Market — нет результатов · `2-search-thrive-no-results.jpg`

## Зона 3. Детальная страница рецепта

### ★ CREME — детальная · `3-detail-creme-hero-stats.jpg`, `3-detail-creme-ingredients.jpg`
[mobbin](https://mobbin.com/screens/d2f83471-26e9-4d91-830e-c58327a643b9) ·
[mobbin](https://mobbin.com/screens/88c17cee-e38a-4bcf-bb1f-c1b455f54629)
- Hero-фото во всю ширину (~55% высоты), низ уходит в `bg` градиентом;
  **название 28–30pt bold поверх фото** у нижнего края.
- Поверх фото — круглые «стеклянные» кнопки 36pt (назад, поделиться,
  избранное) с тач-зоной 44.
- Ряд действий: primary-кнопка с иконкой (персиковая заливка, тёмный текст —
  совпадает с нашим `--accent`/`--accent-fg`) + secondary на `surface`;
  ряд скроллится горизонтально.
- Описание `text-2` с «показать ещё».
- **Блок параметров**: 4 колонки «подпись 13pt `text-3` / значение 15pt
  semibold», сверху и снизу волосяные разделители. Сложность — сегментный
  индикатор из 5 палочек.
- «Ингредиенты» title-2 + справа выпадающий выбор порций «2 portions ⌄».
- Строка ингредиента: миниатюра 32pt, название 15pt, количество 13pt под
  ним, справа круглая кнопка 32pt.
- При скролле — компактная шапка с названием и primary-кнопкой.

## Зона 5. Мой бар (инвентарь)

### ★ Kitchen Stories — поиск по ингредиентам · `5-bar-kitchen-stories-search-by-ingredients.jpg`
[mobbin](https://mobbin.com/screens/2a6c76a0-cbd1-44d6-aa7d-8e8485a6e6f6)
- Под полем — выбранные ингредиенты `×`-чипсами (заливка, без обводки), ниже —
  подсказки обводкой; ряды скроллятся горизонтально.
- Выдача сгруппирована: **«2 out of 4 ingredients»** + чипсы совпавших — совпадение
  показано числом, а не фильтром «да/нет». → наши секции «Можно приготовить» /
  «Не хватает одного».

### ★ Cherrypick — добавить ингредиенты · `5-bar-cherrypick-add-ingredients.jpg`
[mobbin](https://mobbin.com/screens/febcb18b-8c47-4483-a9bd-2add3336413f)
- Шторка поверх шторки фильтров: поиск + чипсы-результаты. Невыбранный —
  обводка и **«+»**, выбранный — тёмная заливка и **«×»**: действие видно до тапа.

### MyFitnessPal — ограничения · `5-bar-myfitnesspal-selected-chips.jpg`
[mobbin](https://mobbin.com/screens/734b01b4-ef69-4c64-940f-5532575a6c89)
- Поиск → выбранные `×`-чипсы → «Common …» плотной wrap-сеткой (чипсы ~32pt,
  gap 6–8). Длинный словарь читается за секунды.

### Recime — «What's in your pantry» · `5-bar-recime-pantry-grid.jpg`
[mobbin](https://mobbin.com/screens/4eeb192b-a2af-4e8a-a69c-7ae2c78da096)
- Сетка 4 колонки «иконка + подпись», сначала «Popular». Без иллюстраций
  ингредиентов нам ближе wrap-чипсы (MyFitnessPal), но порядок «Популярное
  первым» берём.
